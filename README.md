## Arduino Automation Projects

## A collection of Arduino-based automation and embedded system projects using Servo Motors, RFID modules, and I2C LCD displays. These projects demonstrate practical applications of automation, access control, and smart toll booth systems.

## Projects Included

1. Servo Sweep Project

A basic servo motor control project where the servo rotates from 0° to 180° and back continuously.

## Features

Smooth servo movement
PWM-based motor control
Beginner-friendly Arduino project
Components Used
Arduino UNO/Nano
Servo Motor (SG90/MG90S)

## 2. RFID Toll Booth System

An RFID-based smart toll booth system that grants or denies access based on authorized RFID tags.

## Features

RFID authentication
Automatic gate opening and closing
LCD status display
Unauthorized access detection
Servo-controlled gate mechanism

## Components Used

Arduino UNO/Nano
MFRC522 RFID Module
Servo Motor
I2C LCD Display
RFID Tags/Cards

## 3. Simple Toll Gate System

A simple automated toll gate using a Servo Motor and LCD display.

Features
Automatic gate operation
LCD message display
Simple toll gate simulation
Components Used
Arduino UNO/Nano
Servo Motor
I2C LCD Display
